# equipose — Design Context

## Design Context

### Users
Pediatric physiotherapists and clinical researchers running hippotherapy sessions
for children with cerebral palsy (GMFCS III, ages 7–10). They work on a laptop,
often in a bright arena or clinic, to: register a patient, analyze a front/side
video or a single photo, read posture angles plus a snapshot score, and track
progress across a 3–6 month program. They are domain experts, time-pressured, and
handle pediatric medical data. They value speed, legibility, and trustworthy
numbers over delight.

### Brand Personality
Precise, trustworthy, instrument-grade. Voice: factual, restrained, no fluff.
Emotional goal: confidence that the numbers are real and the tool is serious —
calm focus, never playful or noisy.

### Aesthetic Direction
**"Graphite instrument, on paper"** — a warm-**light** clinical workspace styled on
Apple's Human Interface Guidelines: a focused, instrument-grade tool that reads as
a trustworthy medical instrument, not a dev console. (Moved off the original dark
theme — a clinician read the dark UI as "dev-like.")

- **Palette:** a cool paper ground (bg `#E7EDEF`) with **white cards** (`#FFFFFF`),
  near-black navy ink (text `#0C1013`), and slate secondary/tertiary
  (`#415A69` / `#6E8794`). A single **slate-blue emphasis tone** (`#415A69`) for
  actions/active/focus — graphite is the ink, paper the ground. The ONLY hue is
  functional posture status (good=sage `#2E7D52` / watch=ochre `#9A6A12` /
  concern=terracotta `#B0432A`, darkened for AA on light), each carrying a glyph +
  label so it never relies on color alone.
- **Type:** the **system San Francisco stack** (`-apple-system`,
  `BlinkMacSystemFont`, `"SF Pro Text"`, `system-ui`) for everything; numerals
  use **SF Mono / JetBrains Mono** (`ui-monospace`) with tabular figures. SF is
  OS-provided (offline, no files shipped); JetBrains Mono is the only self-hosted
  face. No designer display font.
- **Layout (Apple patterns):** a unified toolbar; the guided Patient→Capture→Read
  steps as a **source-list sidebar**; left-aligned **Large Title** + quiet
  subtitle; content in **inset grouped lists** with hairline separators (System
  Settings style); real **segmented controls**; soft low-alpha elevation; 8-pt
  spacing; Apple continuous-radius geometry (~8–14px), not pills. The Reading
  screen is **answer-first**: a summary hero (score dial + status + plain-language
  "why" + position scale) leads, then the big annotated photo, then the body-chart,
  then the breakdown.
- **Body-chart:** an outlined rider (measured, status-colored) sits on a muted
  **horse** silhouette (context, never a measured value) — the sagittal schematic
  reads as riding, not sitting; it mirrors to the subject's facing.
- **Negative space:** the faint architectural **goniometer field** is kept,
  neutral and ultra-low-alpha, as the measurement-instrument identity; the score
  dial echoes it as a thin precise arc.
- **Anti-references:** AI-slop (accent-caps eyebrows, pills-on-everything,
  card-in-card, radial glows/gradients, trendy display fonts, neon, emoji-as-UI),
  cheap neon blue-black, cream/beige "vibe-coded" palettes, glassmorphism, toy
  aesthetics.

### Design Principles
1. **Calm and clinical.** Cool paper + white cards + navy ink; the tone is
   reassuring and progress-forward. It should read as a medical instrument, not a
   dev console.
2. **One emphasis tone (slate-blue), used sparingly** — actions and emphasis only;
   everything else is cool neutral.
3. **Status is never color alone.** good/watch/concern each carry a text label
   AND a distinct glyph (✓ / ◐ / ▲), so they survive grayscale and are AA.
4. **Numerals are monospaced.** Every measured value uses SF Mono / JetBrains Mono
   for tabular precision; prose uses San Francisco.
5. **One continuous flow, not pages.** The patient stays in context across
   Capture and Read.
6. **Honest restraint.** Clinical/research instrument with placeholder
   thresholds — never over-promise or imply false precision through dazzle.

### Constraints
- **Stack:** Streamlit. Theme via `.streamlit/config.toml` (`base = "light"`) +
  scoped CSS injection (`ui.py`); fonts are the OS-provided system San Francisco
  stack (offline, no CDN) with only JetBrains Mono self-hosted via
  `enableStaticServing` (`static/fonts/`, served at `app/static/`). Layout via
  native primitives + `st.session_state` for the flow.
- **Accessibility:** WCAG AA contrast on the light surface; status not color-encoded alone.
- **Privacy:** local-only, no network calls at runtime (fonts included).
